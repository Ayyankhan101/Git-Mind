# Git-Mind

Multi-agent repository intelligence platform. Enter a GitHub username — 9 AI agents run in parallel and produce architecture diagrams, security audits, CVE scans, code analysis, and a shareable report.

## Language

**Session**:
A single analysis run for one repository. Created when a user submits a repo URL, holds all agent outputs, expires after 7 days.
_Avoid_: run, execution, job

**Agent**:
One of 9 parallel analysis workers (architecture, security, CVE, git audit, Solidity, code audit, API docs, RAG setup, blame enrichment). Each is fully error-isolated — a failure returns safe defaults.
_Avoid_: worker, service, task

**Orchestrator**:
LangGraph state machine that clones the repo via Scanner, then runs all agents in parallel. Manages circuit breaker, event streaming, and state merging.
_Avoid_: pipeline, coordinator, dispatcher

**Scanner**:
First agent in the pipeline. Clones the repo to a temp directory, builds file tree, indexes contents, extracts lockfiles and secrets for Rust acceleration.
_Avoid_: cloner, fetcher

**Analysis**:
Complete result set from all agents for a session. Stored as JSON, pruned after TTL. Frontend reads via `/analysis/{session_id}`.
_Aavoid_: result, output

**Health Score**:
Aggregate quality metric (0-100) computed from agent findings. Streams live during analysis. Displayed on HealthCard component.
_Avoid_: grade, rating, quality score

**RAG (Retrieval-Augmented Generation)**:
Hybrid search pipeline combining ChromaDB vector search + BM25 FTS5, with cross-encoder reranking. Powers the chat feature and auto-fix patches.
_Avoid_: search, retrieval

**Crisis Mode**:
Multi-agent debate simulation for incident response. CEO, Legal, and Engineering agents argue about a live incident; a reporter publishes if the team is too slow.
_Avoid_: incident response, simulation

**PAT (Personal Access Token)**:
GitHub token entered via command bar (Cmd+K). Stored AES-GCM encrypted. Enables private repo access and higher API rate limits.
_Avoid_: token, API key

**ChromaDB**:
Vector database storing code embeddings per session. Used by RAG pipeline for semantic search. Collections pruned after TTL.
_Avoid_: vector store, embeddings DB

**Finding**:
Individual security, CVE, or code audit result with severity (Critical/High/Medium/Low), file location, and remediation advice.
_Avoid_: issue, alert, vulnerability

**Architecture Diagram**:
Mermaid graph showing component relationships. Generated by architecture agent using 24K-token LLM context. Rendered with pan/zoom/fullscreen.
_Aavoid_: system diagram, component graph

**Monitor**:
Background loop that watches subscribed repos. Fetches latest SHAs, triggers re-analysis on change, sends email/webhook notifications.
_Avoid_: watcher, polling service

**Webhook**:
External notification endpoint. Pushes analysis results to configured URLs for CI/CD integration.
_Avoid_: callback, hook

**Rust Native**:
PyO3 module (`gitmind_core`) and solang sidecar accelerating lockfile parsing, secret detection, and Solidity AST generation.
_Aavoid_: Rust extension, native module

**Design Tokens**:
CSS custom properties defining the visual system. Loaded from `design-tokens.css`. Supports 13 themes and 3 density modes.
_Avoid_: theme variables, CSS variables
