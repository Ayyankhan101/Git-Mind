# v0.1

## Added

- Initial React 19 SPA with chat interface
- FastAPI backend with SSE streaming
- RAG pipeline via ChromaDB + Groq (llama-3.3-70b)
- Rust sidecar for git analysis
- Docker compose for local development
- Obsidian vault integration with opencode plugin
- Vault color coding with CSS + Dataview

## v0.1.1 — Redis Hardening + Gap Fixes

### Backend

- `services/cache.py` — Redis retry (3 attempts), production fail-fast, max_connections 50
- `services/task_queue.py` — Redis List (LPUSH/BRPOP), task registry pattern, 3 workers
- `services/session.py` — Redis hash + TTL, in-memory dev fallback
- `services/rate_limiter.py` — Redis sorted set + Lua sliding window
- `llm_cache.py` — Redis primary + diskcache fallback (2-tier)
- `agents/chat.py` — Returns source filepaths from ChromaDB RAG
- `routes/chat.py` — SSE stream includes source metadata
- `requirements.txt` — Added orjson, opentelemetry-api/sdk/exporter

### Frontend

- `api.js` — `postChatStream` accepts sources callback, try/catch on SSE parse
- `ChatTab.jsx` — SourceBadge renders file citations, streaming completion fix

### Fixed

- Dead sources callback in ChatTab (was 5th arg ignored by api.js)
- SSE /chat/stream sent no source metadata (SourceBadge never rendered)
- JSON.parse in SSE reader crashed on malformed lines
- main.py sessions_active counted in-memory dict, not Redis
- task_queue.py missing contextlib import
- task_queue.py used `callable` instead of `Callable` type hint
