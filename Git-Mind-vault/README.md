## How to use

1. **Open** this folder as vault in Obsidian
2. **Graph View** (`Cmd+Shift+G` / `Ctrl+Shift+G`) → full codebase map
3. **Start** at [[Git-Mind Graph]] — main map of content
4. **Explore** [[God Nodes]] for core abstractions, [[Agent Nodes]] for 9 parallel agents
